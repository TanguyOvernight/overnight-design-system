# Images de la démo (`demo/assets/`)

Le code de `demo/index.html` va **automatiquement** chercher ces images (et garde un
placeholder si le fichier est absent). Dépose-les ici avec **exactement ces noms** :

## Jeu de la bouteille (Palmier)
- `bouteille.png` — la bouteille en PNG transparent, ~hauteur 400 px. Affichée en fond du Palmier.

## Cartes (Le Bus & co)
- `dos-carte.png` — le dos de carte (rouge orné avec la lune). Affiché sur la carte centrale.

## Comment les ajouter
Tu ne peux pas me donner un chemin local (`C:\…`) : je tourne dans le cloud, sans accès à ton PC.
Deux options :
1. **GitHub (recommandé)** : sur la branche, `demo/assets/` → *Add file ▸ Upload files* → glisse tes PNG → commit.
2. Tu me les **joins dans le chat** : je te confirme le placement/nommage exact à respecter.

Puis préviens-moi : je rafraîchis le lien live (`s.chat3d.ai/overnight-jab`) sur la nouvelle version et les images apparaissent.
